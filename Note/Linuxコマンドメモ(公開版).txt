***************************
****Windows PSコマンド****
***************************
------------------------------
--接続設定・デバイスの探索--
------------------------------
＊Windowsシステムのネットワークインターフェースを調べる
　%10や %17とかのインターフェース番号を確認
ipconfig

＊ネットワークインターフェースに繋がっている全機器へ一度ピン（Ping）を送り、Windows側にターゲットIPC(Linux)の存在を認識させる（※これをやらないと下の検索に出てこない）
　ff02::1：同じリンク上の全てのノードに送信
　%[インターフェース番号]：上で調べたインターフェース番号
ping ff02::1%[インターフェース番号]

＊DHCPによる自動IP割り当て設定のIPv6のIPアドレスを調べる
　00-01-05：MACアドレスのBeckhoff社のベンダーID (OUI)
Get-NetNeighbor -LinkLayerAddress 00-01-05* -AddressFamily IPv6

＊デバイス指定でピングを飛ばす
　fe80::201:5ff:fexx:xxxx：調べたIPアドレス
　%[インターフェース番号]：調べたインターフェース番号
ping fe80::201:5ff:fexx:xxxx%[インターフェース番号]

＊デバイスへSSH接続する
　fe80::201:5ff:fexx:xxxx：調べたIPアドレス
　%[インターフェース番号]：調べたインターフェース番号
ssh Administrator@fe80::201:5ff:fexx:xxxx%[インターフェース番号]

--基本操作--

exit

【lsコマンドの色意味】
青: ディレクトリ
緑: 実行可能ファイル
水色: シンボリックリンク
赤: アーカイブファイル（.tar.gzなど）
ピンク: 画像ファイル

cat /etc/passwd | cut -d : -f 1

＊実行中のアプリケーション一覧表示
htop



---------------------------------------------------------
--ネットワークインターフェースに固定IPアドレスを設定--
---------------------------------------------------------
＊ネットワークインターフェース一覧表示
ip a
ip addr show
ip link show

＊ネットワークインターフェースの設定ファイルを作成
　touchコマンドで空ファイル作成
sudo touch /etc/systemd/network/10-end0-static.network

＊nanoで開いて編集
デフォルト設定が「20-**」なので、それより先に読み込まれるファイル名にする「10-**」
sudo nano /etc/systemd/network/10-end0-static.network 
---nano input---
[Match]
Name=end0

[Network]
Address=192.168.X.X/24
# Gateway=192.168.1.1 not using Gateway setting
---nano input---

＊ネットワークサービスを再起動(設定が反映されない場合は、2つ目のコマンドでサービス自体を再起動する)
sudo networkctl reload
↓↓反映されない場合の確実な手段↓↓
sudo systemctl restart systemd-networkd


------------------
--AMS NetID変更--
------------------
＊設定ファイルをnanoで開く　/etc/TwinCAT/3.1/TcRegistry.xml
sudo nano /etc/TwinCAT/3.1/TcRegistry.xml
---nano input---
<Value Name="AmsNetId" Type="BIN">XXXXXXXXXXXXXXXX</Value>
AMS NetIDが書いてあるところを探し出して、16進数で入力する(例：192.168.1.2.1.1 にしたい場合は C0A801020101 と入力)
---nano input---
入力後システム再起動必須

---------------------------------
--HMI TF2000使用時インストール--
---------------------------------
＊パッケージを検索(TwinCATで検索しても出ない)　　注：リストを更新後に
sudo apt search tf2000	
＊インストール
sudo apt install tf2000-hmi-server
＊TF2000 Serverの初期化
sudo TcHmiSrv --initialize --password=1
＊ファイヤウォール設定追加（TF2000用の設定作成してhttps用のポート2020を開ける）
sudo nano /etc/nftables.conf.d/20-hmi.conf
---nano input---
table inet filter {
  chain input {
    # accept TcHmi
    tcp dport 2020 accept
  }
}
---nano input---
＊設定リロード
sudo systemctl reload nftables
＊設定追加できているか確認
sudo nft list ruleset
＊TF2000Serverを有効化
sudo systemctl enable TcHmiSrv.service
＊TF2000 Serverのスタート
sudo systemctl start TcHmiSrv.service


-------------------------------
--TF1200を使用時インストール--
-------------------------------
＊インストール
sudo apt install tf1200-ui-client
＊自動ログイン設定(ログインアカウント「TF1200」作成)
＊ディレクトリ移動
cd /etc/TwinCAT/Functions/TF1200-UI-Client/scripts
＊設定変更
sudo ./setup-full.sh --user=TF1200 --autologin --autostart
＊全画面表示設定
＊上記のログインユーザーに切り替え
su TF1200
＊ディレクトリ移動
cd
＊nanoで設定ファイルを開く
nano ./.config/TF1200-UI-Client/config.json
---nano input---
        :
    "enableKioskMode": true,
        :
    "startUrl": "file:///etc/TwinCAT/Functions/TF1200-UI-Client/documentation/TF1200-UI-Client.html",	//デフォルト
    "startUrl": "http://127.0.0.1:2010",	//http
    "startUrl": "https://0.0.0.0:2020",		//https
        :
---nano input---
＊日本語フォントをインストール(再起動必須)
sudo apt install fonts-noto-cjk

--------------------------
--AMS NetIDの16進数計算--
--------------------------
例：192.168.1.2.1.1 → C0A801020101
手順：
1.Windowsの標準アプリ「電卓」を開く
2.メニューから「プログラマー（Programmer）」モードにする
3.DECの欄に「192」と打つと、HEXの欄に「C0」と出る
4.DECの欄に「168」と打つと、HEXの欄に「A8」と出る
5.繰り返してHEXの欄の値を並べれば完成
